The whole thing

A side rail switches between everything below.

Models
Epic, Ballad, Verse, Couplet — best to most basic. They change how it writes and how detailed the thing it builds comes out: Epic gives the drawing pad ten colours, Couplet gives it one.
Chats
Open as many as you like at once, as tabs. Each keeps its own conversation and its own running game. Saved, so they come back later.
Code
A live editor with Run, plus an assistant that edits for you — “make it faster”, “make it green”, “explain this code”.
Notes
Jot notes with a mood, kept on your device.
Network
None. It never calls out to anything.
Also does
Maths with brackets, percentages, unit conversions, dates, counting, dice, timers and jokes — and it forgives typos.
Account
None. Open the link and use it.

Built to run on your device

Instant. No sign-in, no server to wait on, no permission prompts. Open the link and it is already working.

Private. Your chats, your notes and your code stay in your own browser. Nothing you type is sent anywhere.

Yours to keep. Every website and game it makes is a complete, working file — open the Code tab, change it, run it, take it away.
